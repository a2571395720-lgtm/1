# Windows 桌面版验证记录

版本：1.0.0。验证日期：2026-09-26。系统：Windows 11 x64（10.0.26200）。

- `desktop/npm test`：32 项测试，覆盖持久化、恢复副本、简历管理、备份校验、去重、匹配计算、普通字段识别及权限边界。
- 仓库根目录 `npm test`：旧网页版构建及 2 项回归测试通过；`npm run lint` 通过。
- `desktop/npm run test:e2e`：2 项真实 Electron 测试通过，验证界面操作、档案保存、简历副本、职位添加/编辑/筛选/去重、备份恢复、关闭重开，以及隔离申请窗口中的填表和经确认后的附件选择。
- 对 `win-unpacked/JobPilot.exe` 及实际安装后的 `JobPilot.exe` 分别重复上述 2 项端到端测试，全部通过；测试资料使用独立临时目录。
- `desktop/npm run dist` 成功生成 NSIS 安装器。实际安装返回 0，用户目录中的程序、桌面快捷方式、开始菜单快捷方式及卸载记录均存在。
- 使用桌面快捷方式进行普通启动，并再次启动以验证单实例唤起；主窗口标题为「JobPilot · 求职工作台」，进程正常响应。
- 检查安装后的 `app.asar`：仅包含运行源码、界面、图标和包信息，无开发依赖、测试资料、个人档案或简历。

## 重复验证已安装程序

在 `desktop` 目录中运行：

```powershell
$env:JOBPILOT_EXECUTABLE = "$env:LOCALAPPDATA\Programs\JobPilot\JobPilot.exe"
npm run test:e2e
```

若安装时选择了其他位置，将上面的路径改为实际程序路径。测试截图保存在 `artifacts/desktop-qa/`；其中有职位或个人信息的截图使用的是合成测试资料。
